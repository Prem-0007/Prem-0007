# Sources and methodology

The profile image is generated by `scripts/generate-profile.mjs` and refreshed every 12 hours by `.github/workflows/profile.yml`.

| Metric | Source |
|---|---|
| Stars | Sum of stargazers across public, non-fork repositories owned by `Prem-0007` (GitHub GraphQL API) |
| Repositories | Count of public, non-fork repositories owned by the account |
| Followers | Account follower count |
| Merged PRs | Public pull requests authored by the account and merged into repositories owned by someone else (GitHub search) |
| Commits (yr) | Commit contributions in the current contribution window |
| Top languages | Share of code bytes across the 100 most-starred owned repositories, top five shown |
| Top repositories | Four most-starred owned repositories |
| Selected contributions | Merged-PR counts grouped by upstream repository, top five shown |

Private repositories and forks are not counted.

## Running it yourself

```bash
npm install
npm run generate:mock        # offline test with placeholder data
GITHUB_TOKEN=<token> npm run generate
```

The images are written to `assets/`.
